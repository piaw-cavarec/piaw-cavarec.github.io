## 🚀 Déploiement sur GitHub Pages

Le site utilise le standard Web sans aucune dépendance lourde ni étape de compilation :
1. Pousser les modifications sur la branche principale (`main` ou `master`) :
   ```bash
   git add .
   git commit -m "Mise à jour du portfolio"
   git push origin main
   ```
2. Dans les réglages de votre dépôt GitHub (`Settings > Pages`), sélectionnez la branche `main` et le dossier `/ (root)`.
3. Le site est en ligne automatiquement à l'adresse [https://piaw-cavarec.github.io/](https://piaw-cavarec.github.io/).
